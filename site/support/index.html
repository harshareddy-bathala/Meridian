Support

Keep Meridian running.

Meridian is free and open, and like any organisation it has running costs. Support keeps the network up for everyone who uses it, and anything beyond that builds the next station.

What support keeps running.

  • The platform

    The computer that plans every pass, stores every result and serves the dashboard, and the link that puts it online.

  • Data and services

    The services and keys the platform uses to fetch orbit numbers and public satellite data.

  • This site and its address

    The domain, the site and the email address people write to.

  • Upkeep

    Fixes, updates, security patches and reviewing what outside contributors send in.

If support goes further.

Anything beyond running costs goes, in this order, to:

  1. A tracking antenna

    An antenna that turns to follow each satellite across the sky, so the station can receive more satellites, and more of every pass.

  2. More stations

    Stations in other places, so a pass one station loses to cloud or a building another can catch.

  3. New software

    The next features: more satellites, better predictions and more ways to use the data.
