For developers

Run it, build on it, or help write it.

Meridian is Apache-2.0, and every figure it publishes can be rebuilt from a dataset, a config file and a seed.

Run the whole platform.

One machine, one command. It brings up the platform, its database, the dashboard and its monitoring, on a laptop or a Raspberry Pi, in under ten minutes from a clean start.

git clone https://github.com/harshareddy-bathala/Meridian.git && cd Meridian
cp deploy/.env.example deploy/.env
docker compose -f deploy/docker-compose.yml up -d --build

Then open http://localhost:8080/ for the dashboard. The runbook covers the rest: the practice fleet, backups, alerts and going public.

Help write it.

Python for the platform and TypeScript for the dashboard, with C++ for the antenna's motor controller to come. Every change comes with tests, and every decision is written down with what was rejected and why, so nothing has to be learned by asking. The source and the decision log are in the repository.
