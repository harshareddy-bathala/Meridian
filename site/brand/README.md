# Brand assets

Generated by `python site/tools/make-images.py --what brand`. Do not edit the PNGs by hand — regenerate them.

## Which file

| Use | File |
|---|---|
| **Profile picture** (GitHub, X, LinkedIn, Discord) | `meridian-mark-onblack-2048.png` |
| Profile picture on a light-themed platform | `meridian-mark-onpaper-2048.png` |
| Overlay on a dark background | `meridian-mark-light-*.png` (transparent) |
| Overlay on a light background | `meridian-mark-dark-*.png` (transparent) |
| Banner, header, slide title | `meridian-lockup-onblack-2048.png` |
| An upload form that refuses PNG | `meridian-mark-onblack-2048.jpg` |
| Design tools, vector work | `meridian-mark.svg` |

Each mark ships at 2048, 1024 and 512 px. Start at 2048 and let the platform downscale; every one of them does it better than a second round of resampling here would.

**PNG, not JPEG.** The mark is two hairline strokes on flat ground, which is the worst case for JPEG — no alpha channel, and visible ringing around the strokes at exactly the sizes an avatar gets displayed at. A PNG of a two-stroke vector is around 100 KB, so there is nothing to gain. The one JPEG exists for upload forms that reject PNG and is not the file to reach for otherwise.

## Clear space and minimum size

The mark's outer diameter is **62% of the frame**, centred. That is not an aesthetic choice: an avatar is cropped to the inscribed circle on most platforms, and at 62% the crop never touches the limb. Do not crop these files tighter.

**Minimum size is 24 px.** The mark was drawn to survive small — two strokes, no fill, no accent — but below about 24 px the meridian arc closes up against the limb and it reads as a plain circle.

Do not add a wordmark beside the square mark yourself; use the lockup, where the spacing is measured rather than eyeballed.

## Colours

| | Hex |
|---|---|
| Ink, on dark | `#E8E6E1` |
| Ink, on light | `#14161B` |
| Dark ground | `#08090D` |
| Light ground | `#FAF9F7` |

Never pure white and never pure black — both grounds are warm, and the ink is matched to them. The three signal colours (`--signal`, `--alert`, `--trace` in `site/style.css`) are semantic: they mean *above horizon*, *below horizon* and *predicted*. They are not brand colours and must not appear in a logo treatment.

## The geometry

The limb is a circle of radius 22 in a 64-unit box; the meridian is the left half of an ellipse about the same centre with a horizontal radius of 10.5 — a sphere's limb and one meridian under orthographic projection, which is the same construction `site/main.js` draws on the canvas and the same one in `site/favicon.svg`.

`make-images.py` draws it from a single `mark()` function, so the rasters and the vector cannot drift apart.
